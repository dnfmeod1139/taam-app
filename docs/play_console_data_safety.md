**작성일**: 2026-05-20
**대상**: TAAM PWA (com.playtaam.app)
**작성 기준**: 코드 전체 분석 (index.html, Supabase 스키마, Edge Functions, sw.js)

## 📍 위치

```
Play Console → 앱 콘텐츠 → 데이터 보안
```

---

## 🎯 진행 순서

```
1. 데이터 수집 여부 → "예" 선택
2. 데이터 유형별 체크 (아래 표)
3. 각 데이터 유형별 상세 답변 (수집 목적·공유 여부·필수 여부)
4. 보안 관행 답변
5. 검토 및 제출
```

## 3️⃣ 각 데이터 유형별 상세 답변

각 체크된 항목마다 다음 4가지 질문에 답변:

### 공통 답변 패턴

#### Q1. 이 데이터가 수집됩니까, 공유됩니까?
→ **수집됨** (앱이 직접 수집)

> ⚠️ "공유"는 제3자에게 데이터를 넘기는 경우. PortOne/Supabase는 "처리 위탁자"이지 "공유 대상"이 아님. 모두 **"수집됨"** 으로만 표시.

#### Q2. 데이터 수집이 필수입니까, 선택입니까?
→ 항목별로 다름 (아래 표)

#### Q3. 데이터 수집 목적은?
→ 항목별로 다름 (아래 표)

#### Q4. 사용자가 데이터 수집을 거부할 수 있나요?
→ 항목별로 다름

---

### 📋 항목별 상세 답변표

#### ① 대략적 위치
- **공유?**: 수집됨
- **필수?**: ❌ 선택
- **목적**: 앱 기능 (지도에 가까운 레스토랑 표시)
- **사용자 거부 가능?**: ✅ 예 (위치 권한 거부 가능)

#### ② 이름
- **공유?**: 수집됨
- **필수?**: ✅ 필수
- **목적**: 
  - 앱 기능 (마이페이지 표시·예약 발급)
  - 계정 관리
- **사용자 거부 가능?**: ❌ 아니요 (가입에 필요)

#### ③ 이메일 주소
- **공유?**: 수집됨
- **필수?**: ✅ 필수 (해외 회원), ❌ 선택 (한국 회원, SMS 인증 시)
- **목적**:
  - 계정 관리 (로그인 ID)
  - 사용자 통신 (OTP 인증·중요 공지)
- **사용자 거부 가능?**: ❌ 아니요 (가입에 필요)

#### ④ 전화번호 (한국 회원만)
- **공유?**: 수집됨
- **필수?**: ❌ 선택 (해외 회원은 미수집)
- **목적**:
  - 계정 관리 (SMS OTP 인증)
  - 사용자 통신
- **사용자 거부 가능?**: ✅ 예 (해외 회원으로 가입 시 이메일만)

#### ⑤ 구매 내역
- **공유?**: 수집됨
- **필수?**: ✅ 필수 (구매 시)
- **목적**:
  - 앱 기능 (티켓·멤버십 발급)
  - 분석 (수익 통계)
  - 사기 방지
- **사용자 거부 가능?**: ❌ 아니요 (구매하면 자동 기록)

#### ⑥ 앱 내 메시지 (TAAM Chat)
- **공유?**: 수집됨
- **필수?**: ❌ 선택 (Chat 사용 시만)
- **목적**:
  - 앱 기능 (Chat AI 응답)
  - 분석 (서비스 개선)
- **사용자 거부 가능?**: ✅ 예 (Chat 미사용 가능)

#### ⑦ 앱 상호작용
- **공유?**: 수집됨
- **필수?**: ❌ 선택
- **목적**:
  - 분석 (사용 패턴 파악)
  - 앱 기능 (예약·티켓·즐겨찾기)
- **사용자 거부 가능?**: ✅ 예 (앱 사용 안 하면)

#### ⑧ 기기 또는 기타 ID (FCM 토큰)
- **공유?**: 수집됨
- **필수?**: ❌ 선택 (푸시 알림 권한 동의 시만)
- **목적**:
  - 앱 기능 (푸시 알림 전송)
- **사용자 거부 가능?**: ✅ 예 (푸시 권한 거부 가능)

## 4️⃣ 보안 관행 답변

### 데이터 암호화

**"데이터가 전송 중 암호화됩니까?"**
→ ✅ **예** (HTTPS · Vercel + Supabase 모두 TLS 1.3)

### 사용자 데이터 삭제 요청

**"사용자가 데이터 삭제를 요청할 수 있나요?"**
→ ✅ **예**

**삭제 요청 URL 또는 이메일**:
```
support@playtaam.com
```

(또는 마이페이지에 "계정 삭제" 기능 추가 권장 — 현재 미구현. 이메일 요청 처리로 일단 대응)

### 가족 안전 정책

**"앱이 어린이용입니까?"**
→ ❌ **아니요** (TAAM 멤버십은 18세 이상)

### 데이터 보안 관행

각 항목 모두 ✅:
- ✅ 데이터가 전송 중 암호화됨
- ✅ 사용자가 데이터 삭제 요청 가능
- ✅ 데이터 보안 표준 (예: ISO 27001 — Supabase 인증)

## 5️⃣ 검토 및 제출

모든 항목 입력 후:
1. 화면 하단 **"검토 후 제출"** 또는 **"저장 및 다음"**
2. 요약 화면에서 빠진 항목 없는지 확인
3. **"제출"** 또는 **"게시"**
4. 좌측 사이드바 "데이터 보안" 옆 ✅ 표시

## ⚠️ 자주 묻는 함정

### 함정 1: "공유" vs "수집"
- PortOne/Supabase 같은 **처리 위탁자** → 공유 아님
- Google Analytics, 광고 SDK 등 **분석 도구** → 공유
- TAAM은 자체 인프라(Supabase)만 사용 → **모두 "수집됨"** 으로만 답변

### 함정 2: 결제 정보
- 우리는 카드번호 직접 저장 안 함 (PortOne 빌링키만)
- → "결제 정보" 체크 ❌
- 대신 **"구매 내역"** 만 체크 ✅

### 함정 3: 위치
- "대략적 위치" = 도시 단위
- "정확한 위치" = GPS 좌표
- TAAM은 지도 표시용 대략적 위치만 → **"대략적"** ✅, **"정확한"** ❌

### 함정 4: 어린이용
- TAAM은 멤버십(유료) + 와인 페어링 → 어린이용 아님
- → **"아니요"** 명확히
