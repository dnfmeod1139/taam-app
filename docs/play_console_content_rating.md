## 4️⃣ 예상 결과 (등급)

답변 모두 입력 후 → IARC가 자동으로 등급 산출:

| 지역 | 예상 등급 |
|---|---|
| 🌐 IARC Generic | **3+** (모두) |
| 🇰🇷 Korea (게임물관리위) | **전체이용가** |
| 🇺🇸 ESRB (북미) | **Everyone** |
| 🇪🇺 PEGI (유럽) | **PEGI 3** |
| 🇯🇵 (CERO) | **A (전 연령)** |

→ 모든 지역에서 **가장 낮은 연령 제한** 으로 통과.

---

## 5️⃣ 등급 확정

자동 산출된 등급 확인 → **"확정"** 또는 **"적용"** 클릭

→ 좌측 사이드바 "콘텐츠 등급" 옆에 ✅ 체크

---

## ⚠️ 한 가지 주의 — 멤버십 가격 표시 의무

콘텐츠 등급 자체와는 별개로, 멤버십 결제가 있는 앱은:
- 데이터 보안에서 "결제 정보 수집" **반드시 체크**
- 자세한 설명에 "유료 멤버십 서비스 포함" 명시

→ `play_console_data_safety.md` 참고.
