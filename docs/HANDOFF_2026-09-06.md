## 넘어가지 말 것 (이 저장소의 규칙)

- `index.html` 은 4.7MB 단일 파일. **편집 전 rebase, 끝나면 즉시 머지.**
- SQL 은 저장소에 두는 것 ≠ 적용. 새 SQL 은 「⚠ 실행 필요」를 명시하고
  **채팅에 전문을 붙인다**(링크 금지). 확인 쿼리는 union all 로 **하나만**.
- 잔액은 `profiles` 를 직접 update 하지 않는다 — RPC 에 **델타**를 넘긴다.
- 사진은 base64 금지(index.html 도 DB 도). Storage URL 만.
- 픽스처는 짐작하지 말고 라이브 모양을 베낀다 — 이 세션에서만 두 번 틀렸다
  (`expires_at` 없는 컬럼, 날짜가 `2026.09.20` 인데 `-` 로 만듦).
- 검증은 시크릿 창을 **전부 닫고** 새로 하나만 연다.
